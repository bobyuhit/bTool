# bTool

**面向 ESP 系列的图形化工具** —— 固件烧写、芯片信息、串口终端、文件传输，收在一个窗口里。

单文件 Tkinter 程序，打包后是一个**免安装的 exe**：拷到任何 64 位 Windows 上双击就跑。

---

## 能做什么

| 功能 | 说明 | 板上要跑什么 |
|---|---|---|
| **固件烧写** | 多文件按地址烧写；地址按文件名自动识别 | — |
| **芯片信息** | 型号 / 修订版 / 封装 / MAC / 晶振 / 特性串 / Flash 分区表 | — |
| **串口终端** | 面向 MicroPython 的交互式终端，支持行编辑、历史回溯、剪贴板 | MicroPython |
| **文件传输** | 主机 ↔ 设备文件系统之间的双向传输 | MicroPython |

> **芯片识别和烧写不依赖板子里烧了什么固件。** 它们走的是芯片**出厂自带的 ROM
> bootloader** —— 裸机板、Arduino、出厂一片空白，一样认得出来。
>
> 串口终端和文件传输是 MicroPython 专属功能；板上没有时，界面会把对应按钮置灰
> 并说明原因，而不是让你点了报错。

## 支持的芯片

```
ESP32 / ESP32-S2 / ESP32-S3        ESP32-C2 / ESP32-C3 / ESP32-C5
ESP32-C6 / ESP32-C61 / ESP32-E22   ESP32-H2 / ESP32-H21 / ESP32-H4
ESP32-P4                            ESP8266
```

（esptool 5.x 认得的都支持。）

## 下载 / 运行

### 方式一：直接用 exe（推荐）

到 **[Releases](../../releases)** 下载 `bTool.exe`，双击即用。**不需要装 Python。**

- 免安装、免配置，可以拷到任何 64 位 Windows 上跑
- 首次运行 Windows SmartScreen 可能拦一下（exe 未签名）：**更多信息 → 仍要运行**
- ⚠ **串口驱动要自己装**（CH343 / CH340 或 CP210x）—— 那是系统驱动，exe 带不了

### 方式二：从源码跑

```bash
pip install pyserial esptool   # esptool 必须 5.x
python btool.py
```

### 方式三：自己打包

见 [开发说明.md](开发说明.md) 的「打包成单文件 exe」一节。

## 快速上手

1. **插上板子** —— 顶部「串口」下拉会自己刷新，出现 COM 口就能用（没出现是驱动没装）
2. **点「连接」**
3. **烧固件** → 切到「烧写」页：添加固件 → 点「擦除并烧写」
4. **看芯片信息** → 点「烧写」页的「读芯片信息」按钮
   （⚠ 会把板子复位一下 —— 要跟芯片里的 ROM 说话，只能先复位进下载模式）
5. **和板子对话** → 切到「REPL 终端」页，直接在里面敲

界面分三个页签：**烧写** / **REPL 终端** / **文件管理**。中英文随时切换。

> ⚠ 两个要留意的操作：
> - **「先擦除整片 Flash」会连 NVS 里的标定 / 配网数据一起清掉** —— 平常更新程序别勾
> - **「读芯片信息」会复位板子** —— 跑着的程序会重启
